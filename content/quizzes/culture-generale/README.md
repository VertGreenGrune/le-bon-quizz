# Culture générale française — niveau difficile

25 questions (histoire, géographie, littérature, arts, sciences, institutions), chacune avec un
« 💡 Le saviez-vous ? ». Types : 8 choix multiples (dont un « cochez toutes les bonnes réponses »),
5 réponses libres (petites fautes tolérées), 3 vrai / faux, 4 curseurs, 2 ordres, 2 « Mytho ! ».
1000 points, 2000 pour les questions 5, 8 et la finale (25). Pas d'image.

Import (toujours en privé) :

```
pnpm --filter @lbq/server quiz:import content/quizzes/culture-generale <e-mail du compte>
```

Sources : Wikipédia (articles de chaque sujet), site de l'Académie française.
