# Harry Potter — niveau expert : crédits et sources

Import (quiz **privé**, mis à jour s'il existe déjà sous ce titre) :

```
pnpm --filter @lbq/server quiz:import content/quizzes/harry-potter <email de l'animateur>
```

Les images et sons sont copiés dans le dossier d'upload du serveur (`UPLOAD_DIR`) et référencés
depuis `PUBLIC_URL` (par défaut `http://localhost:3001` ; option `--base-url`). Un son absent est
ignoré avec un avertissement : relancez l'import après avoir ajouté les fichiers.

## Musiques à ajouter (non fournies)

Aucun extrait musical n'est distribué avec le projet (droits d'auteur). Déposez vos propres copies
dans `audio/` sous ces noms exacts (MP3, ≤ 10 Mo), puis relancez l'import. Le dossier a son propre
`.gitignore` : vos fichiers restent sur votre disque et ne partent jamais dans git. Le début de
l'extrait dépend de votre version : ajustez « Début de l'extrait » dans l'éditeur si besoin.
