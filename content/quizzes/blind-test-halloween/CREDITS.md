# Blind test d'Halloween : crédits et sources

Import (quiz **privé**, mis à jour s'il existe déjà sous ce titre) :

```
pnpm --filter @lbq/server quiz:import content/quizzes/blind-test-halloween <email de l'animateur>
```

Les images et sons sont copiés dans le dossier d'upload du serveur (`UPLOAD_DIR`) et référencés
depuis `PUBLIC_URL` (par défaut `http://localhost:3001` ; option `--base-url`). Un son absent est
ignoré avec un avertissement : relancez l'import après avoir ajouté les fichiers.
