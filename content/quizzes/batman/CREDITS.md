# Batman, la série animée — niveau expert : crédits et sources

Import (quiz **privé**, mis à jour s'il existe déjà sous ce titre) :

```
pnpm --filter @lbq/server quiz:import content/quizzes/batman <email de l'animateur>
```

L'image est copiée dans le dossier d'upload du serveur (`UPLOAD_DIR`) et référencée depuis
`PUBLIC_URL` (par défaut `http://localhost:3001` ; option `--base-url`). Ce quiz n'a pas de son.

recoupés quand une source était seule. Abréviations : **BTAS** =
[Batman: The Animated Series (Wikipédia EN)](https://en.wikipedia.org/wiki/Batman:_The_Animated_Series),
**BTAS-FR** = [Batman (série télévisée d'animation, 1992) (Wikipédia FR)](<https://fr.wikipedia.org/wiki/Batman_(s%C3%A9rie_t%C3%A9l%C3%A9vis%C3%A9e_d%27animation,_1992)>),
